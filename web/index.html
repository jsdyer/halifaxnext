A little context before you go

Times use Halifax local time. This is an independent passenger information tool. A missing vehicle or prediction does not mean a trip is cancelled. Check Halifax Transit for detours, accessibility and last-minute changes.

Privacy and saved stops

Stop searches run in your browser. Selecting a stop sends its public stop ID to CoolCode’s gateway to retrieve Halifax Transit data. The optional location button uses your browser’s location permission; coordinates stay in this page. Saving a stop stores its ID on this device. No account, cookies or sign-in is needed. An open map requests tiles from OpenStreetMap. CoolCode counts aggregate tool visits.
